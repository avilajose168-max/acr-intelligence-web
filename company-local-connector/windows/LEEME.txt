ACR INTEGRITY - CONECTOR LOCAL VERSION 3

Conecta una carpeta de Windows con el panel Empresas. Admite las pruebas
de conexion y los respaldos reales autorizados por el administrador.
No elimina archivos de la nube ni del disco.

1. En ACR Integrity, entra como administrador y selecciona la empresa.
2. En Almacenamiento y servidor local, guarda un nombre y una carpeta absoluta.
   La carpeta ya debe existir en tu PC o unidad compartida. Tu cuenta de Windows
   necesita permiso de lectura y escritura en ella.
3. Extrae TODOS los archivos de este ZIP en una carpeta de tu PC.
4. Necesitas Python 3.10 o posterior, de https://www.python.org/downloads/windows/
5. En la plataforma pulsa Generar codigo de vinculacion. Dura 10 minutos y sirve
   una sola vez. Generar otro codigo revoca la vinculacion anterior.
6. Abre INICIAR_CONECTOR.cmd, pega el codigo cuando lo pida y pulsa Enter.
   El codigo no se muestra al pegarlo. Confirma con S la carpeta que aparece.
7. Deja la ventana abierta. En la plataforma pulsa Probar conexion.
8. Cuando indique Guardado verificado, pulsa Recuperar desde el servidor.
   El conector LEE el archivo del disco y la plataforma verifica la respuesta.

ARCHIVOS DE PRUEBA
Se crean dentro de la carpeta autorizada:
ACR_Conexion_Prueba / anio / mes / identificador / informe.html
No se reemplazan archivos existentes con contenido distinto.

CONEXION Y SEGURIDAD
El conector realiza conexiones HTTPS salientes; no abre un servidor ni puertos.
No necesita tu contrasena de ACR Integrity ni una clave de administrador.
La credencial queda cifrada con Windows DPAPI para tu cuenta de Windows en
LocalAppData\ACRIntegrityConnector\prueba. No compartas ese directorio.
La vinculacion de este piloto dura 7 dias. Puedes revocarla desde Empresas.
Si vence o la revocas, usa VINCULAR_DE_NUEVO.cmd con un codigo nuevo.

SI NO FUNCIONA
Mantén tu PC encendido, la ventana del conector abierta y la carpeta disponible.
Comprueba Python con py --version. Si Python no esta instalado, instalalo desde
su sitio oficial. No cambies politicas de seguridad ni desactives el antivirus.
Si la empresa bloquea Python o el acceso a internet, solicita apoyo a su TI.
El panel solo marca exito cuando el archivo leido coincide con el original.
Ctrl+C detiene el conector. No se instala como servicio de Windows en este piloto.

INFORMES REALES
Si ya vinculaste este PC con la version anterior, deténla con Ctrl+C antes de
iniciar esta version. Conserva la vinculacion de tu cuenta de Windows.
En Empresas > Respaldo de informes reales puedes copiar un informe publicado
para comprobarlo y activar la copia automatica de informes con todos sus
compromisos completados. Esta copia no confirma efectividad ni elimina originales.
Los informes se guardan en ACR_Informes / anio / mes / informe / version.
Cada carpeta contiene paquete.json, informe.html, manifest.json y las evidencias
incluidas (PNG, JPG, WEBP o PDF). El paquete conserva los datos originales y el
historial; el HTML es una consulta local imprimible. La aplicacion permite
recuperar la version desde el disco y visualizarla con el formato del informe.
Una lectura verifica tambien cada evidencia y el manifiesto. Si falta un archivo
o cambio su contenido, no se confirma la recuperacion. No se usan enlaces externos
como sustitutos de evidencias guardadas. Maximo 32 MB por version.
Los usuarios recuperan solo sus informes autorizados. El administrador consulta
los de su empresa. Nadie recibe acceso para explorar carpetas desde la aplicacion.
La nube conserva los originales durante esta etapa; no se libera almacenamiento.

PROTOCOLOS Y PROCEDIMIENTOS
El administrador general envia el documento original desde Protocolos o
Procedimientos. El conector guarda PDF, Word, Excel o imagen dentro de:
ACR_Documentos / Protocolos o Procedimientos / anio / mes / documento / version.
Solo se publica despues de escribir el archivo y leerlo de nuevo con su huella.
Cada consulta lee el archivo original del disco y su manifest.json. La plataforma
verifica el contenido y retira la copia temporal de transferencia al entregarlo.
No hay una copia permanente de estos nuevos documentos en Storage. Las cargas
interrumpidas vencen a las 24 horas; las lecturas temporales, a los 15 minutos.
La limpieza de transferencias se ejecuta cada 5 minutos. El catalogo permanece.
Los miembros autorizados consultan mediante la aplicacion; no exploran carpetas.
El servidor debe estar encendido, conectado y con este conector abierto.
Si ya hay vinculacion vigente, se reutiliza. Deten primero el conector anterior.
